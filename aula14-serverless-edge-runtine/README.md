# 🚀 Função Edge - Monitoramento de Execução

## 📋 Sobre o projeto
Este projeto apresenta uma Edge Function executada na plataforma Vercel.
A função foi desenvolvida para demonstrar como uma aplicação pode ser executada próxima ao usuário por meio da infraestrutura Edge, retornando informações sobre a execução da função.
A API retorna:
- Mensagem de sucesso;
- Horário do servidor;
- Região onde a função foi executada;
- Tempo de execução da função.
